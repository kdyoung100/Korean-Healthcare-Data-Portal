      PORTAL INTRODUCTION · 포털 소개

      원본이 아닌 메타데이터로 연결하는
      안전한 보건의료데이터 중개 포털

      본 포털은 민감한 원본 데이터를 유출하는 곳이 아니라, ‘메타데이터’라는 안전한 명세서를 통해 흩어진 데이터를 찾아주고 연결해주는 곳입니다. 여러 의료기관·공공기관에 분산된 보건의료데이터를 한곳에서 안전하게 탐색하고 활용할 수 있도록 지원합니다.

      메타데이터란? 중개 포털이란? 설립 목적 서비스 개념도 주요 기능 이용자 유형별 안내
      1

      메타데이터(Metadata)란?

      메타데이터는 데이터를 설명하는 데이터(Data about Data)입니다.

      보건의료데이터는 환자의 민감한 개인정보를 포함하고 있어 원본을 그대로 공유하거나 이동하기 어렵습니다. 본 포털에서 활용하는 ‘메타데이터’는 민감한 원본 데이터를 직접 포함하지 않고, 해당 데이터의 구조·특성·위치·품질 정보만을 설명하는 ‘안전한 요약표이자 카탈로그’ 역할을 합니다.

      이를 통해 연구자는 자신에게 필요한 데이터가 어디에 있는지 빠르고 정확하게 사전 탐색할 수 있으며, 데이터 공급자는 데이터 유출 위험 없이 안전하게 데이터를 알릴 수 있습니다.

      2

      메타데이터 기반 보건의료데이터 중개 포털이란?

      전국 어디서나 안전하고 편리하게 활용 가능한
      보건의료데이터 혁신 생태계

      보건의료데이터 중개 포털은 여러 의료기관 및 공공기관에 흩어져 있는 방대한 보건의료데이터를 한곳에서 쉽게 찾고 활용할 수 있도록 지원하는 통합 플랫폼입니다. 본 포털은 원본 데이터를 직접 수집하여 저장하지 않고, ‘메타데이터’를 중심으로 수요자와 공급자를 매칭하는 안전한 맞춤형 탐색 및 중개 환경을 제공합니다.

      3

      설립 목적

      과거에는 연구 가치가 있는 보건의료데이터가 각 기관에 개별적으로 분산되어 있어, 연구자가 이를 파악하고 접근하는 데 큰 어려움이 있었습니다. 특히 의료기관에서 생성되는 민감정보는 외부 반출이 제한되어, 다른 연구 데이터와 달리 ‘어떤 기관이 어떤 데이터를 보유하고 있는지’ 탐색하는 것 자체가 어려웠습니다.

      본 포털은 이러한 물리적 한계를 극복하고 데이터 수요자와 공급자를 안전하게 연결하기 위해 설립되었습니다. 수요자 및 공급자 중심의 통합 중개 기반을 구축하여 산재된 보건의료데이터의 균형적인 활용을 촉진하고, 누구나 데이터 자원에 접근할 수 있는 혁신적인 보건의료 연구 생태계를 조성하는 것을 목적으로 합니다.

      4

      서비스 개념도

      공급자가 보유한 데이터에서 메타데이터를 추출·제공하면, 중개 포털이 이를 표준화하고, 수요자는 이를 탐색하여 안전하게 신청·중개받습니다.

      5

      주요 기능

      ①

      데이터셋 및 상세 항목 검색, 코호트 생성

      여러 기관에 산재된 국가 보건의료데이터를 한 곳에서 검색할 수 있습니다. 일반 데이터셋 검색부터 상세 항목 검색, 그리고 실제 연구에 활용 가능한 대상 집단(환자 수 등)의 규모를 사전에 추정하는 코호트 생성을 할 수 있습니다.

      ②

      데이터맵 및 (가칭)데이터 디렉토리

      기관별 보유 데이터 현황을 한 눈에 빠르고 직관적으로 파악할 수 있도록
      ① 시각화된 데이터맵 제공
      ② 국가 보건의료데이터 디렉토리 제공

      ③

      다기관 데이터셋을 이용한 연구 지원

      다기관 데이터 활용 시 발생하는 행정 부담을 대폭 줄여줍니다.
      ① 공동 데이터심의위원회(DRB) 기능
      ② 공통서식 작성으로 기관별 서식 자동 생성 기능

      ④

      데이터 공급자용 데이터 활용 지원

      의료기관에 배포되는 전용 소프트웨어로 원데이터에서 메타데이터를 자동 추출·변환합니다. 또한 데이터 결합·가공을 위한 비식별화, 가명처리, 결합키 등을 지원합니다.

      🔐
      핵심 메시지

      국가 보건의료데이터를 한 곳에서 안전하고 쉽고 빠르게 찾을 수 있습니다.

      HOW IT WORKS · 이용 절차

      데이터 탐색부터 활용 승인까지
      4단계로 진행됩니다

      검색으로 필요한 데이터셋을 찾고, 신청·심의를 거쳐 승인된 경로로 안전하게 활용하기까지의 절차를 안내합니다.

      01

      데이터 탐색

      키워드·주제·기관별 검색으로 필요한 데이터셋을 탐색하고 DCAT 2.0 기반 메타데이터를 확인합니다.

      02

      데이터 신청

      연구계획서와 필요 서류를 온라인으로 제출하여 데이터 이용 신청서를 작성합니다.

      03

      DRB 심의

      공용(중앙) DRB 또는 기관 DRB의 심의를 거쳐 이용 적합성을 검토합니다.

      04

      데이터 활용

      승인 후 안심활용센터 또는 승인된 경로로 데이터를 안전하게 활용합니다.
